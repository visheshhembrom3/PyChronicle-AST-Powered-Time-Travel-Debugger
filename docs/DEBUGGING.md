# PyChronicle Debugging

PyChronicle records Python program execution and variable changes
during a debugging session.

## Debugging Features

- First step
- Previous step
- Next step
- Last step
- Historical state inspection
- Watch Variables
- Execution history

## Time Travel

Recorded execution states can be revisited by moving backward
or forward through the execution timeline.

Historical executions are preserved as read-only records, while
the current workspace remains editable.
